# Offerwall catalogs

Automated snapshots of game offers + milestones from KashKick, Freecash and TesterUp.

- `output/` — one xlsx per platform per run (Games Overview + Milestones Breakdown)
- `data/<platform>/<ts>.json` — compact JSON per run (dashboard source)
- `runs.jsonl` — one summary line per processed run, with integrity checks
